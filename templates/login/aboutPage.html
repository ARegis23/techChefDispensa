Sobre o Projeto

Tema escolhido

O projeto TechChef Despensa tem como tema o desenvolvimento de uma aplicação web para verificação dos alimentos e sua parte nutricional conforme compra ou uso dos usuários.

Objetivo do projeto

O objetivo da aplicação é auxiliar usuários na verificação nutricional dos alimentos, fornecendo informações detalhadas sobre os produtos, como ingredientes, valor nutricional e possíveis alergênicos. A aplicação visa promover uma alimentação mais consciente e saudável, facilitando a escolha de alimentos adequados às necessidades e preferências dos usuários.

Nesta etapa inicial, o sistema está sendo estruturado com autenticação, gerenciamento de usuários, rotas protegidas e integração com Firebase, preparando a base para o desenvolvimento das demais funcionalidades.
